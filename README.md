# Site de vente de fournitures scolaires

## Présentation du projet

Ce projet est un site web de démonstration permettant de présenter un catalogue de fournitures scolaires. Il a été réalisé dans le cadre de ma formation en développement d’applications afin de mettre en pratique mes compétences en développement web et en gestion de bases de données.

## Fonctionnalités

- Affichage d’un catalogue de fournitures scolaires.
- Organisation du code selon le modèle MVC (Modèle-Vue-Contrôleur).
- Gestion des données à l’aide de PHP et SQL.
- Affichage des produits et de leurs informations.
- Simulation du processus de commande avec un message de confirmation.

## Technologies utilisées

- **HTML5** : structure des pages web.
- **CSS3** : mise en forme et présentation.
- **PHP** : logique applicative côté serveur.
- **SQL** : gestion des données.
- **Architecture MVC** : séparation des responsabilités entre modèles, vues et contrôleurs.
- **Git et GitHub** : gestion des versions et hébergement du code source.

## Installation et lancement

1. Installer [XAMPP](https://www.apachefriends.org/).
2. Cloner ou télécharger ce dépôt GitHub.
3. Placer le dossier du projet dans le répertoire `htdocs` de XAMPP.
4. Démarrer Apache et MySQL depuis le panneau de contrôle XAMPP.
5. Configurer la connexion à la base de données selon la configuration du projet.
6. Ouvrir le projet dans un navigateur à l’adresse :

   `http://localhost/mon-projet-scolaire/`

**Remarque :** la base de données doit être créée et configurée selon les besoins du projet. Les instructions exactes dépendent de la structure de la base de données utilisée.
